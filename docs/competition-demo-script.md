# Five-minute competition demo script

**0:00–0:35 — Problem and boundary.** Open Campus Ops in Workbench. Explain that
the Manifest defines the contract while seven selected CodeEvidence excerpts add
explicit implementation context; the model never receives ambient filesystem
access. Show the evidence hash and exclusions.

**0:35–1:20 — AI generates, a human governs.** Open the plan matrix and AI call
ledger. Generate candidates, batch-approve a low-risk case, then individually
review the authorization case. Emphasize immutable revisions and risk-bound
approval.

**1:20–2:15 — Attack the behavior.** Launch fixed + authorization-defect targets
with Mutation and record mode. Show independent run IDs, failure-bundle link,
mutation killed/survived counts, and replay telemetry. Replay the failure without
calling the live dependency.

**2:15–3:10 — Explain the failure with evidence.** In Failure Inbox, preview the
redacted bundle before authorizing AI Analysis. Show observed facts, earliest
divergence, evidence citations, hypothesis confidence and missing evidence.

**3:10–3:45 — Hand off the repair.** Generate Handoff Bundle. Copy its MCP URI
and human-readable task. Explain that a Coding Agent reads bounded evidence and
code with its own permission, while AgentQAKit remains the independent verifier.

**3:45–4:35 — Prove the repair.** Select the preconfigured fixed target to
simulate the external repair. Rerun preflight, point to changed source/runtime
hashes, resume, rerun, and compare. Show the authorization case moving to FIXED.

**4:35–5:00 — Release decision.** Run regression and mutation gates, then export
WorkflowReport. Close on reproducibility: strict schemas, checksums, transparent
UNOBSERVABLE metrics, Mock browser acceptance, and optional real DeepSeek evidence.
